Overview

What this project does

A full-stack GEOINT demonstrator that maps where political violence and protests occurred in Poland, lets analysts filter and chart the record, and surfaces per-city forecasts — with an offline evaluation that compares forecasting methods on a temporal holdout.

Research questions

What I set out to answer

  • Can ACLED data be served through a web GIS with filtering, clustering, and charts without page reloads?
  • What spatial and temporal patterns appear in Poland's event record?
  • How well do moving average, naive, and Random Forest models predict city-month counts on held-out data?
  • Is the in-app moving average defensible given the accuracy–interpretability trade-off?

Key findings

What the evaluation showed

  • Random Forest achieved the lowest error (MAE 1.50; RMSE 2.84) on a 12-month holdout.
  • The 3-month moving average used in the app (MAE 2.38) beat the naive baseline (MAE 2.54) while staying traceable.
  • The pipeline from ACLED CSV → GeoJSON → forecast JSON is documented end-to-end in the paper.
