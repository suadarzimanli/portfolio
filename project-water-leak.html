Overview

What this project does

Eight pressure zones report hourly flow and pressure with daily demand peaks and weather. Hidden leaks persist until repaired, alongside events that look like leaks: scheduled hydrant tests and valve work, unscheduled hydrant use, drifting pressure sensors and hot-weather demand. Rules, a logistic regression and the model plus a context check are compared on leaks caught and false alerts rather than accuracy. Operators work each incident from acknowledgement to close-out and see what the simulation really contained only after deciding.

Research questions

What I set out to answer

  • How do threshold rules and a learned model compare in leaks detected and false alerts when leak-like operational events are present?
  • Does training the model with those look-alike events reduce its false alerts?
  • How many false alerts does a context check using only operator-visible information remove, and what does it cost in missed leaks?
  • How can a dashboard teach the path from alarm to close-out without showing what an operator could not know?

Key findings

What the study showed

  • The learned model caught more leaks than the rules (376 vs 308 of 400) but raised 2.5× as many false alerts.
  • Training with hydrant tests, valve work and demand peaks did not reduce false alerts: in flow and pressure they look like small leaks.
  • A context check using the published schedule, the weather and whether pressure fits the flow cut false alerts from 1.02 to 0.19 per zone-week (−81%) while losing 7 of 400 leaks.
