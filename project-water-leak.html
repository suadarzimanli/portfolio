Overview

What this project does

A browser-based teaching dashboard that simulates flow and pressure readings across eight network zones, trains logistic regression in JavaScript, and walks operators through acknowledge → dispatch → close-out — keeping an open incident as the case record, not only a map colour.

Research questions

What I set out to answer

  • Does persisting an operator incident with workflow steps make leak monitoring easier to understand than map colours alone?
  • Does a zone map plus a short history chart help interpret a suspicious reading in context?
  • Can maintenance, weather, and scenario labels help users think about false positives before dispatch?
  • What can we learn by running ML and rules-only detection on the same simulated stream in one UI?

Key findings

What the design study showed

  • Open incidents gave a place to hang workflow and logs while the map kept updating; a close-out queue models readings that look normal before paperwork is finished.
  • Selecting a zone pans the map and shows the last 48 readings — enough to practise reading space and time together on synthetic data.
  • Context panels and hydrant/valve scenarios highlight false-positive situations; side-by-side ML vs rules mode is mainly for comparison in teaching, not production tuning.
