User Request Export

Desktop DBF / FPT export & enrich tool

← Back to Projects GitHub

A Windows .NET 8 WinForms utility for Visual FoxPro / dBase tables: export to CSV or Excel, read memo text from companion .fpt / .dbt files, and enrich an existing spreadsheet by key. Built as a local desktop tool (not a web service) to make large DBF exports faster and safer.

The engine accepts any matching DBF + memo pair you select (same base name). Help text and the automated verify harness use large sample tables as examples; field names for enrich are chosen from the loaded schema (with optional guesses such as common key/memo column names).

.NET 8 Windows Forms DBF / FPT ClosedXML CSV / Excel

What it does

  • Open DBF schemas (fields, record counts, encoding) and validate structure before export
  • Pair and validate FPT/DBT companions (basename match, memo pointer sanity)
  • Export all or selected fields to CSV or Excel, with atomic writes
  • Preserve awkward cell content: commas, quotes, newlines, non-ASCII, formula-like leading characters
  • Enrich a base Excel/CSV by matching keys and copying a DBF field into a new column
  • Fail closed: after export/enrich, re-read the output and compare against the DBF; delete mismatched files
